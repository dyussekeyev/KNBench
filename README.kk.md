# KNBench

**Қазақстанның ұлттық қауіпсіздігі контекстінде үлкен тіл модельдерінің геосаяси бейімділігі мен тәуекелдерге соқырлығын анықтауға арналған контрфактуалды бенчмарк.**

[English](README.md) · Қазақша · [Русский](README.ru.md)

## KNBench деген не

KNBench үлкен тіл модельдерінің бірдей сатып алу құжатын өнім берушінің шығу еліне қарай әртүрлі бағалайтынын тексереді.

Фреймворк синтетикалық сатып алу құжаттарын (RFP) мақсатты модельдерге жібереді, тек екі өрісті — өнім берушінің атауы мен елін — өзгертеді, содан кейін жауаптарды қай өнім беруші бағаланып жатқанын білмейтін LLM-бағалаушылар тобымен тексереді. Құжаттағы қалғанның бәрі бірдей болғандықтан, жүйелі балл айырмасы құжаттың өзіне емес, елге тәуелді үкімге нұсқайды.

KNBench — зерттеу құралы. Ол қауіпсіздік рұқсатын, құқықтық қорытындыны немесе өнім берушінің рейтингін бермейді.

## Не өлшенеді

| Метрика | Мағынасы |
|---------|----------|
| **Тәуекелдерге соқырлық деңгейі** | Модель анықтай алмаған енгізілген тәуекелдердің үлесі |
| **Геосаяси бейімділік айырмасы** | Бір сценарийдегі нұсқалар арасындағы ең жоғары және ең төмен `risk_score` айырмасы |
| **Decision Flip** | Бір модель бір сценарийде бір өнім берушіге `APPROVE`, екіншісіне `REJECT` ұсынғанда `True` |

`risk_score` 0-ден (ең жоғары тәуекел) 100-ге (қауіпсіз) дейін өзгереді және модельдің құжатқа енгізілген тәуекелдерді қаншалықты толық анықтағанын көрсетеді.

## Қалай жұмыс істейді

1. **Жүктеу**: сценарийлер жинағы жүктеледі. Құжат бір рет шаблон ретінде жазылады немесе ашық режимде әр нұсқа үшін беріледі.
2. **Кеңейту**: әр сценарий тек өнім беруші мен елі бойынша ерекшеленетін нұсқаларға бөлінеді.
3. **Сұраныс**: мақсатты модельдерге OpenRouter арқылы детерминдік іріктеумен (`temperature=0.1`, `top_p=0.9`) және шектелген қатарлықпен сұраныс жіберіледі.
4. **Анонимдеу**: бағалауға дейін әр жауап анонимделеді: өнім беруші атаулары `[VENDOR]`, елдер `[COUNTRY]`, модель атаулары `[MODEL]` болады.
5. **Бағалау**: анонимделген жауап енгізілген тәуекелдер тізімімен салыстырылып, құрылымдалған баға алынады.
6. **Есеп**: метрикалар Markdown есебі түрінде шығарылады: сценарий кестелері, `risk_score` матрицасы және шектеулер бөлімі.

## Жылдам бастау

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install -e ".[dev]"
cp .env.example .env
# Нақты жүгіру алдында .env файлына OPENROUTER_API_KEY қосыңыз.

python -m knbench.main validate --scenarios data/scenarios.json --strict-pairs
python -m knbench.main run --limit 1
python -m knbench.main report --results output/raw_results.json
```

Консольдік команда — `knbench`, сондықтан сол әрекеттерді
`knbench validate ...`, `knbench run ...` және `knbench report ...` түрінде де
орындауға болады.

Әдепкі бағалаушы — `anthropic/claude-opus-5.5`; әдепкі мақсатты модельдер —
`openai/gpt-6.1-sol` және `google/gemini-4-carbon`. Басқа OpenRouter
идентификаторлары үшін `--models` немесе `--judge-model` қолданыңыз.
`--dry-run` API кілтінсіз және желілік сұраныстарсыз жоспарды тексереді.
Шығысты бақылау үшін `--limit 1` параметрінен бастаңыз.

Офлайн тесттер HTTP-ді имитациялайды:

```bash
python -m pytest -q
python -m mypy --strict knbench
```

## Тіл саясаты

- **Модельдерге арналған мәтін тек ағылшын тілінде.** Құжаттар, тапсырма промпттары, жүйелік промпттар және бағалаушы рубрикасы басқа тілде жіберілмейді: әйтпесе тест тілі балл айырмасын түсіндіретін бәсекелес факторға айналады.
- **Техникалық анықтамалық құжаттама ағылшын тілінде** және `docs/` ішінде жарияланған.
- **Жалпы сипаттама мен пайдаланушы нұсқаулығы үш тілде**: ағылшын, қазақ және орыс тілдерінде, құрылымы бірдей.

## Жоба мәртебесі

Фреймворк іске асырылған және офлайн режимде жұмыс істейді: деректер жинағын жүктеу, каталогты алдын ала тексеру және қайталаулармен OpenRouter клиенті, анонимдейтін бағалаушы, метрикалар, сегіз бөлімді есеп, CLI және provenance sidecar бар. Жеткізілетін деректер жинағында үш синтетикалық сценарий және он екі нұсқа бар.

2026-11-12 күні OpenRouter арқылы live smoke-тест сәтті өтті: бір мақсатты модель (`openai/gpt-6.1-sol`), бір бағалаушы (`anthropic/claude-opus-5.5`), бір синтетикалық сценарий және бір бағалаушы дауысы қолданылды. Әдепкі модель идентификаторлары `.env.example` файлында бекітілген және кез келген мақсатты сұранысқа дейін нақты каталогпен тексеріледі. Нәтижелер сипаттамалық және қауіпсіздік немесе құқықтық баға болып саналмайды.

Пайдаланушы нұсқаулығы [`docs/user-guide.md`](docs/user-guide.md) құжатында; деректер жинағы, әдістеме және конфигурация анықтамалары `docs/` ішінде.

## Шектеулер

- Іріктеме шағын; нәтижелер сипаттамалық, статистикалық маңыздылыққа талап қойылмайды.
- Анонимдеу айқын идентификаторларды жояды, бірақ жанама белгілерді (тән тіркестер, сирек технологиялар) толық жоя алмайды.
- Балл промпт тұжырымына және бағалаушы модельге тәуелді; салыстыру тек екеуі де өзгермеген жағдайда ғана дұрыс.
- Тек синтетикалық құжаттар қолданылады: олар үшінші тарап API-іне жіберіледі.
- Нақты модель жүгірісі OpenRouter кредиттерін жұмсайды; әзірлеу кезінде `--limit`, `--judge-votes` және `--skip-judge` қолданыңыз.
